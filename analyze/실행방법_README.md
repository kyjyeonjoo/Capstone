# 🚦 교통법규 위반 분석 시스템 구동 가이드

본 폴더(`rum`)는 다른 컴퓨터나 외부 환경으로 이동하더라도 **인터넷 연결 없이 즉시 구동될 수 있도록 모든 의존 파일이 패키징된 완전 독립 환경(Standalone Env)**입니다.

## 🚀 1. 가장 쉬운 '자동 실행' 방법 (추천)

윈도우(Windows) 사용자라면 복잡한 명령어 입력 없이 원클릭으로 서버를 가동할 수 있습니다.

1. 현재 폴더에 있는 **`run.bat`** 파일을 **더블 클릭**합니다.
2. 검은 터미널 창이 뜨면서 자동으로 파이썬 필수 프로그램(`requirements.txt`)들을 설치합니다.
3. 잠시 후 서버가 띄워졌다는 메시지가 나오면 창을 끄지 마시고 그대로 둡니다.
4. 크롬(Chrome)이나 엣지 등 웹 브라우저를 열고 주소창에 아래 주소를 입력합니다.
   👉 **http://localhost:8000**
5. 블랙박스 영상(.mp4)을 드래그 앤 드롭으로 업로드하여 분석 결과를 확인합니다.

---

## 💻 2. 직접(수동) 실행 방법

만약 `run.bat` 자동 스크립트가 먹히지 않거나, 맥(Mac)/리눅스 환경에서 가동하실 경우 터미널(명령 프롬프트)을 열고 아래 명령어를 순서대로 입력하세요.

```bash
# 1. 필수 라이브러리 설치
pip install -r requirements.txt

# 2. 백엔드 폴더로 진입
cd backend

# 3. FastAPI 웹 서버 구동
python -m uvicorn main:app --reload
```
(*실행 후 브라우저 접속 주소는 `http://localhost:8000` 로 동일합니다.*)

---

## 📁 3. 패키지 폴더 구조 설명

이 폴더 내부는 다음과 같은 체계적인 아키텍처로 짜여 있습니다.

* `backend/` : FastAPI 기반의 강력한 백엔드 서버와 다중 모델을 제어하고 중복을 제거하는 `yolo_inference.py` 핵심 추론 로직이 들어있습니다.
* `frontend/` : 사용자와 상호작용하는 웹 디자인(HTML, CSS, JS) 요소가 모여있습니다.
* `models/` : 신호위반, 안전모, 중앙선침범, 진로변경 등 4종류의 핵심 딥러닝(.pt) 가중치 모델 파일들이 들어있습니다.
* `yolov5/` : 오프라인 오지 환경에서도 딥러닝 연산이 정상 구동되도록 삽입된 뼈대 소스코드입니다.
* `run.bat` : 윈도우 사용자 전용 더블클릭 서버 가동 스크립트입니다.
* `requirements.txt` : 파이썬 서버 가동을 위해 반드시 필요한 설치 목록입니다.
